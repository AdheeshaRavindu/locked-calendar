Privacy Policy — Locked Calendar

Last updated: 2026-06-08

Introduction

Locked Calendar ("we", "us", "Locked Calendar") provides an offline-first journal application that encrypts notes on-device and optionally syncs an encrypted backup to your Google Drive appData folder. This policy explains what we collect, how we use it, and your choices.

What we collect

  • Account data: None required by the app itself — users only connect their Google account if they enable Cloud sync.
  • Sync file: When Cloud sync is enabled, Locked Calendar stores a single JSON file named locked-calendar-sync.json in the user's Google Drive appDataFolder. That file contains only ciphertext (AES‑GCM encrypted note fields) and minimal metadata (vault id, timestamps).
  • Local data: The master password is not stored. A salted Argon2id hash and a per-device KDF salt are stored locally. OAuth refresh tokens are encrypted locally before storage.
  • Usage analytics: None by default.

How we use data

Sync: The encrypted sync file enables two‑way sync between devices that share the same master password.

Support & security: Contact information you provide may be used to respond to support or security issues.

Data sharing and third parties

We use Google Drive App Data to store the encrypted sync file. Google acts as a storage provider for ciphertext only and never receives plaintext note content from the app. We do not sell or rent personal data.

Security

All note content is encrypted locally with AES‑GCM using a key derived from the master password before any data is written to disk or uploaded. OAuth refresh tokens are encrypted on-device before local storage. We follow standard security practices but cannot guarantee absolute security; users must keep their master password safe.

Retention

Local copies of encrypted notes and metadata are kept on-device until you delete them. The sync file in Google Drive appData persists until you delete it from Drive or disconnect; disconnecting from the app clears local sync credentials but does not automatically delete the file from Google Drive.

User controls

  • Disconnect: Settings → Cloud sync → Disconnect clears local encrypted tokens.
  • Export / delete: Use the app’s export feature to create a local decrypted backup or delete notes in the app to remove them from future syncs.

OAuth status

The Locked Calendar OAuth client is currently in Testing (unverified) mode. In this state Google limits access to up to 100 test users. If you are comfortable remaining in testing mode, no additional action is required. To remove the 100-user limit and publish publicly, the developer must complete Google OAuth verification and branding steps.
