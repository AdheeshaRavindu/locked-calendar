# Demo recording script — Locked Calendar

Use this script to record a 30–90 second verification video demonstrating OAuth consent and sync.

1. Start recording (30–90s total). Keep narration short and clear.
2. Show the app window and open Settings → Cloud sync. (Caption: "Settings → Cloud sync — Not connected")
3. Click **Connect Google account**. When the browser opens, show the Google consent screen with scopes visible. (Caption: "Google OAuth consent screen — requesting Drive appData")
4. Complete consent flow and return to the app. Show Settings now displaying `Connected` and the last sync timestamp. (Caption: "Connected — sync ready")
5. Open the editor, create or modify a note (type a few words). (Caption: "Create or edit a note")
6. Open Settings and click **Sync now**. Show the success message: "Synced ... Applied N remote update(s)."
7. Click **Disconnect** and show Settings returns to `Not connected`. (Caption: "Disconnect clears local tokens")
8. Stop recording.

Recording tips:
- Blur or crop any personal email addresses if you prefer.
- Use clear, short captions for each step.
- If possible, record at 30–60 fps and compress to MP4 for upload.

Optional reviewer step (include only if you can provide reviewer access):
- Provide a temporary test Google account and a 2-hour window when the reviewer can sign in and follow the same steps locally.
